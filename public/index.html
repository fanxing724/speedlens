这些检测能说明什么？ ＋

分流：只有返回 IP 的检测点能提供出口证据。对 ChatGPT 等普通网站，我们通常无法得知该站看到的源 IP，需要结合 VPN 客户端连接日志判断命中规则。

IP 纯净度：查询 IPQuery 的 VPN、代理、Tor、数据中心标记和风险分；其未提供的滥用记录保持未知。没有标记不能保证原生住宅、账号注册成功或永不触发风控；数据中心也不等于恶意。

网站测试：并发 3 个、每个最多 7 秒；使用无凭据的 no-cors 请求，不读取你的登录信息。跨域隔离或防追踪策略可能影响结果；毫秒值是浏览器请求耗时，不是 ICMP Ping。

WebRTC：只显示本次 ICE 收集到的 host / srflx 候选；mDNS 地址不是可直接读取的 IP。观察到与 HTTPS 不同的公网 IP 值得检查，但双栈与不同路由也会造成差异。本工具不提供完整 DNS 泄漏测试。

隐私：第三方检测站点会看到你的连接 IP。风险查询经过本站后端，并把目标 IP 发送至标明的数据源；服务不保存检测历史、不使用分析追踪器。托管平台和第三方可能保留访问日志。历史记录保存在此浏览器，可随时清除。
