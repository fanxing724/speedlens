检测说明与隐私 ＋

浏览器视角：出口、分流和网站请求均从你当前浏览器发起，经过此浏览器的 VPN 与规则；Render 后端只用于公网 IP 数据查询和可选测速。

纯净度：IPQuery 返回 VPN、代理、Tor、机房标记及其风险分。未标记不保证原生住宅、不触发风控或服务可用；没有数据的滥用字段显示未知。备用 ipwho.is 仅提供归属地。

分流边界：表格标明实际探针域名，只展示可以读取的出口。不同子域名、IPv4 / IPv6、缓存与浏览器策略都可能影响结论；失败不直接意味着 VPN 关闭或目标被封。

数据与隐私：开启自动检测后会向列出的第三方请求 IP 与连通性。点击 IP 或运行分流表会把目标 IP 发送至本站后端和 IPQuery，失败时使用 ipwho.is。历史仅保存在本机；服务不接入广告或统计。平台与第三方可能保留访问日志。

检测范围：服务连通性不是解锁测试，WebRTC 不是完整泄漏证明，本版本不提供完整 DNS 泄漏测试。关闭自动检测可改为手动启动。
